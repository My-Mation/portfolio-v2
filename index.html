FEATURED 01 — AVEENIR HACKATHON🏆 1ST PRIZE WINNERTEAM PROJECT

CHEAT-PROOF.

HARDWARE.

AWARD: 🏆 1ST PRIZE WINNER — AVEENIR HACKATHON TIME BIND: BUILT IN 48 HOURS TYPE: HARDWARE + EMBEDDED C++ + LOCAL WEB AP + AI ENGINE TEAM: TEAM PROJECT

OSAMU is an anti-cheat hardware terminal system that replaces vulnerable online exams. It broadcasts encrypted questions to ESP32 student keypads, evaluates responses with zero bias, and adaptively generates deep-dive questions when students struggle.

01 / HARDWARE ISOLATION (ANTI-CHEAT)

Standard digital exams fail because students switch tabs, use secondary phones, or consult AI tools. OSAMU runs on isolated, standalone ESP32 physical hardware terminals equipped with tactile keypads, timers, buzzers, and offline Wi-Fi access points. No internet access, no tab switching, no cheating possible.

02 / UNBIASED ADAPTIVE DEEP-DIVES

Grading is 100% objective without teacher bias or favoritism. The system tracks response latency, key hesitations, and answer accuracy in real time. If a student shows hesitation on a concept, OSAMU dynamically generates targeted follow-up questions to test deep understanding rather than surface memory.
